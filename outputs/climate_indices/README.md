# outputs/climate_indices/ — Index Characterization

Standalone characterization of ONI (ENSO), DMI (IOD), and MEI v2 — timeseries, phase counts, climatology figures — **before** event-linked driver pipelines.

## Purpose

Document the large-scale indices themselves (distributions, annual cycle, phase frequency) used later to tag MHWs.

## On-disk layout

Paths are nested historically:

```
outputs/climate_indices/climate_indices/
├── enso/{csv,figures}/
├── iod/{csv,figures}/
└── mei/{csv,figures}/
```

Key CSVs include `oni_timeseries.csv`, `dmi_timeseries.csv`, `mei_timeseries.csv`, plus climatology / phase-count tables.

## Generated by

| Index | Script |
|-------|--------|
| ENSO / ONI | `src/climate/scripts/enso_analysis.py` |
| IOD / DMI | `src/climate/scripts/iod_analysis.py` |
| MEI v2 | `src/climate/scripts/mei_analysis.py` |

## Upstream / Downstream

| Upstream | Downstream |
|----------|------------|
| `data/raw/oni.nc`, `dmi.had.long.nc`, `meiv2.nc` | `outputs/enso|iod|mei/` pipelines; ML climate features via `src/ml/common.py` |

## Notes

- **DMI ends April 2025** → late-2025 IOD phases may be `Unknown` in event tables.
- Phase thresholds used project-wide: ENSO/MEI ±0.5; IOD ±0.4.
- If ML loaders expect `climate_indices/enso/csv/...` without the extra nesting, verify path resolution after reorg.
