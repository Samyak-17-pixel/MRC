# outputs/climate_comparison/ — ENSO vs IOD vs MEI Ranking

Composite comparison of the three large-scale drivers across lag, frequency, statistics, annual, seasonal, and strength evidence.

## Purpose

Produce a side-by-side ranking so the project can state which index is the strongest large-scale associate of BoB MHWs (**IOD #1** in all three regions).
