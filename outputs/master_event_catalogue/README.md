# outputs/master_event_catalogue/ — Per-Event Master Table

Merges **every analyzed parameter** for all **117** MHW events into one analysis-ready table (117 rows × 57 columns).

## Purpose

Single join of SST, climate-index lags/phases, wind, and heat-flux fields for multivariate work, publication tables, and event-level ML verification.

## Key files

| File | Contents |
|------|----------|
| `csv/all_regions_master_event_catalogue.csv` | All 117 events |
| `csv/{region}_master_event_catalogue.csv` | Per-region subsets |
| `csv/{region}_01_event_sst.csv` … `_04_heat_flux.csv` | Category splits |
| `csv/column_glossary.csv` | Column definitions |
| `csv/regional_summary_statistics.csv` | Regional aggregates |
| `figures/` | Tables, heatmaps, timelines, dashboards, top-event panels |

## Generated by

`src/climate/scripts/build_master_event_catalogue.py`
