# results/mhw_catalogue/ — Central MHW Event Database

The single most important data product of the project: the catalogue of all detected Marine Heatwave events. **Every downstream analysis (ENSO/IOD/MEI, wind, heat flux, master catalogue, ML labels) reads from these three files.**

## Contents

| File | Region | Events |

**Total: 117 events, 1,795 event-days (2006–2025).**

## Column Schema

| Column | Type | Meaning |
|--------|------|---------|
| `Start_Date` | date | First day SST exceeds the Hobday 90th-percentile threshold (of a ≥5-day run) |
| `End_Date` | date | Last day of the run above threshold |
| `Duration_Days` | int | End − Start + 1 (minimum 5 by definition) |
| `Mean_Intensity` | float °C | Mean of (SST − Threshold90) over the event |
| `Max_Intensity` | float °C | Maximum of (SST − Threshold90) during the event |

Intensity is measured **relative to the seasonally varying 90th-percentile threshold**, not to the climatological mean — this is the Hobday et al. (2016) convention used throughout the project.

## How It Was Produced

1. `scripts/extract_regional_sst.py` — daily regional-mean SST from Copernicus data.
2. `scripts/build_hobday_climatology.py` — day-of-year climatology (11-day window) and smoothed 90th-percentile threshold.
3. `scripts/detect_mhw.py` — flags days above threshold and groups runs of ≥5 consecutive days into events.

Full detection methodology: [`documentation/05_mhw_detection.md`](../../documentation/05_mhw_detection.md).
