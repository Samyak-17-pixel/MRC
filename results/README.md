# results/ — All Analysis Outputs

Every output of the climate-analysis pipeline. CSV tables are the numerical record; PNG/PDF figures are regenerable from scripts (and are excluded from Git — see root `.gitignore`).

**The single master summary of every number in this folder:** [`ALL_PROJECT_RESULTS.md`](../ALL_PROJECT_RESULTS.md).

---

## Folder Map

### Core data products

| Folder / file | Produced by | Contents |
|---------------|-------------|----------|
| `combined_sst_2006_2025.nc` | `merge_sst.py` | Merged daily SST cube (~3.2 GB, not in Git) |
| `{north,central,south}_bob_sst.csv` | `extract_regional_sst.py` | Regional daily mean SST (Date, SST) |
| `{region}_bob_sst_detrended.csv` | `detrend_sst.py` | Detrended variants |
| `{region}_wind.csv` | `extract_regional_wind.py` | Regional daily wind speed |
| `climatology/` | `build_hobday_climatology.py` | `{region}_hobday.csv` (DOY, Climatology, Threshold90) + spatial NetCDFs + figures |
| **`mhw_catalogue/`** | `detect_mhw.py` | **The central event database** — see its README |

### MHW reporting

| Folder | Contents |
|--------|----------|
| `annual_statistics/` | Per-year event counts, durations, intensities per region |
| `event_reports/{north,central,south}/` | Per-year event CSVs |
| `top_events/` | Top-10 strongest / longest per region |
| `figures/` | Core MHW figures (counts, durations, intensity vs year) |
| `2016/ … 2026/` | Per-year SST maps and regional time series |
| `mhw_summary.txt`, `master_summary.csv` | Text/CSV overall summaries |

### Climate indices & driver analyses

| Folder | Contents |
|--------|----------|
| `climate_indices/{enso,iod,mei}/` | Index characterization: time series CSVs + climatology figures |
| `enso_lag/`, `enso_frequency/`, `enso_statistics/`, `enso_annual/`, `enso_seasonal/`, `enso_strength/` | 6-stage ENSO pipeline outputs (see `enso_analysis/README.md`) |
| `enso_analysis/` | Comprehensive ENSO–MHW figures + per-event plot folders |
| `iod_lag/ … iod_strength/`, `iod_analysis/` | Same 6-stage structure for IOD |
| `mei_lag/ … mei_strength/` | Same 6-stage structure for MEI v2 |
| `climate_comparison/` | ENSO vs IOD vs MEI composite ranking (7 CSVs, 59 fig pairs) |

### Local drivers

| Folder | Contents |
|--------|----------|
| `wind_analysis/` | Weak/strong wind classification per event, 117 per-event plots, climatology comparison |
| `heat_flux/` | Regional SLHF/SSHF time series |
| `heat_flux_analysis/` | Flux anomalies during MHWs, reduced-loss flags |

### Synthesis

| Folder | Contents |
|--------|----------|
| `master_event_catalogue/` | 117 events × 57 parameters + 76 figures — see its README |
| `top_event_sst_maps/` | SST lifecycle maps for top-10 strongest + longest per region (3,329 PNGs) |
| `spatial_analysis/` | Spatial composites, trends (Mann–Kendall, Sen's slope), EOF (partial) |
| `maps/` | Base maps and per-variable map collections |
| `publication/` | Publication-ready tables (T01–T03), figures (F01–F05), top-5 triptychs, dashboards |

## Key Statistics (for orientation)

- **117 MHW events**: North 49, Central 40, South 28 (2006–2025)
- **81%** of events during anomalously weak wind
- **IOD** = strongest large-scale driver in all regions
- Longest event: South, 81 days (2024-06-14 → 2024-09-02); strongest: South, 0.943 °C (2024-04-14)

## Regenerating

Any figure here can be regenerated by the corresponding script in `scripts/` (see `scripts/README.md` for the mapping and run order). CSVs are deterministic given the raw data in `datasets/`.
